# Scottish banners docs overview

- Re-audit (2026-09-19): banners represent the arms of the chief/lord in 1471; evidence ranked seal, contemporary roll, near-period same line, retrospective tradition, reconstruction. Modern "clan arms" are not automatic evidence.
- SDD high-priority: seven banners to improve; runtime authority is `config/poc.config.json` (clan XML untouched); targets show shield arms, never full achievements.
- Icon tiles: new charges were painted into the banner icon atlases and compiled, but not yet referenced by any banner key as of writing ([[banner-icon-atlas-editing]], [[banner-icon-psd-autoimport]]).
- Tartan set: SUPERSEDED. Named clan tartans are 18th-19th century and anachronistic; armorial banners replaced them.
