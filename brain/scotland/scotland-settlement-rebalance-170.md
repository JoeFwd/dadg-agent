# Scotland settlement rebalance 170

Status: DEPLOYED and independently audited (2026-08-30). The plan file itself lives outside the repo (a desktop visualisations folder); only the ledger and one brief are in `.superpowers`.

- Target roster: 170 settlements (16 / 29 / 125), one Forth marker removed, northern and maritime support expanded, flat economy replaced by explicit Scottish tiers. Mountain interiors are reserved for a later hideout pass.
- Kirkwall initially had no Orkney land or navmesh and Aros/Glenelg/Killean crossed disconnected components; resolved by placing via Dornoch/Portmahomack and removing component exceptions. Spacing >= 8 enforced, external reference and economy validation added.
- Scene hierarchy lesson (user-corrected after the first cache regeneration): capsules are TOWN REGIONS, not singleton settlement parents. Rule taken from the English layout: a town region; castles under the nearest town; villages under their bound fort; the parent sits at the bbox midpoint at z=20. Final: 16 regions / 170 children, English 28 regions untouched.
- Deployment: first atomic replace was rejected by Windows and restored; use explicit one-use swap backups.
- The Default distance cache was regenerated by the user in the installed v1.4.8 editor after deployment.
- Locked unchanged: navmesh and terrain were byte-identical throughout.
